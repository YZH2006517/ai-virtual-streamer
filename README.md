# AI虚拟主播

Windows 上的 AI 数字人唠嗑直播助手：一个 Live2D 主播看着抖音弹幕陪观众聊天，还能跳舞、玩弹幕小游戏。

下载一个 exe 就能用，用你自己的大模型 API Key。语音和大模型都在云端，**必须联网**。

> **关于显卡：** 这个版本不需要独立显卡，因为它**只有微软 Edge 在线语音，不包含本地 TTS**，也不能克隆声音。
> 本地 TTS（如 GPT-SoVITS）需要性能较好的独立显卡，这个版本不支持。

## 能做什么

- **人设**：内置多个主播人设，性格、声音、场景一键换，也可以自己写
- **读弹幕回答**：读抖音直播间网页的留言，排队回答，留言多时合并回答，支持屏蔽词
- **舞台跳舞**：跟着背景音乐的节拍跳
- **弹幕小游戏**：猜数字、答题挑战（大模型现场出题，可选类别和难度），有积分榜和排行榜大屏
- **礼物心愿**：礼物攒够了自动跳舞或开一局游戏
- **画面可调**：每个场景的组件、位置、图层都能单独调
- **账本**：今天花了多少 token、礼物进了多少

## 怎么用

1. 到 [Releases](../../releases/latest) 下载最新的 `.exe`，双击运行
   - Windows 可能提示「已保护你的电脑」：这是因为 exe 没有代码签名，点「更多信息 → 仍要运行」
   - 第一次启动要解压，等十几秒
2. 按提示填大模型 API Key（推荐 [DeepSeek](https://platform.deepseek.com/)，也支持其他 OpenAI 兼容接口）
3. 在「活动」「人设」里选好，点「控制 → 抖音弹幕」填直播间地址
4. 在「输出」页复制直播画面地址，用 OBS 或直播伴侣采集

## 导入自己的 Live2D 模型

**第一步：准备模型**

- 需要 Cubism 3 及以上的模型，文件夹里要有 `.model3.json`；Cubism 2 的 `.model.json` / `.moc` 不支持
- VTube Studio 的模型文件夹可以直接用
- 贴图、动作等文件要放在模型文件夹里，不能引用文件夹外面的文件
- 先看模型作者的授权，确认你的用途被允许（见下面的「非商用声明」）

**第二步：打包**

把整个模型文件夹压缩成 `.zip`。zip 的文件名就是软件里显示的形象名，空格和点号会变成下划线。

**第三步：导入**

1. 打开「人设」页，点开最下面的「形象」
2. 小动物、吉祥物勾上「是动物 / 吉祥物」，默认全身显示；人物不用勾，默认半身显示
3. 点「导入 Live2D 模型（zip）」，选择压缩包

**第四步：使用**

在「形象」列表里点一下模型就换好了，当前人设也会记住。想调整位置和大小，到「组件 → 掌柜」。

**常见问题**

| 情况 | 原因和处理 |
|---|---|
| 提示「没有找到 .model3.json」 | 压缩包里没有 Cubism 3 及以上的模型文件，检查是不是压错了文件夹或是 Cubism 2 模型 |
| 说话时嘴不动 | 模型要有 `ParamMouthOpenY` 参数，或在 `.model3.json` 里配置 LipSync 组 |
| 模型显示不完整 | 检查贴图是否在模型文件夹内；单个文件超过 200 MB 会被跳过 |
| 只导入了一个模型 | 一个 zip 只导入一个模型，有多个时分开打包 |

- 只会解压 `json`、`moc3`、`png`、`jpg`、`wav`、`mp3` 文件
- 用同样的 zip 文件名再次导入，同名文件会被覆盖
- 模型保存在 `%LOCALAPPDATA%\AI虚拟主播\data\avatars`；想删除时，关掉软件后删掉对应文件夹

## 运行要求

- Windows 10 / 11（64 位），需要 [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/)（Win11 自带）
- 显卡：不需要独立显卡。Live2D 用 WebGL 绘制，要有能正常工作的显卡驱动；目前没有在低配电脑上系统测试过，集成显卡的流畅度以实际运行为准
- 需要联网：大模型、语音（微软 Edge 在线语音）都在云端，断网时不能用
- 不包含本地 TTS。如果在大模型设置里选本地 Ollama，硬件要求取决于你运行的模型
- 你的数据都在本机 `%LOCALAPPDATA%\AI虚拟主播`，API Key 用 Windows DPAPI 加密保存

## 使用须知

- 大模型按量计费，费用由你自己的账号承担
- Edge 语音是微软的在线服务，读弹幕是读取直播间网页，都不是官方开放接口，可能随时失效；请自行确认是否符合平台规则
- 直播时画面上的「AI 生成」标识请保留，这是平台和法规的要求
- 不要诱导观众打赏，未成年人不得打赏

## 从源码运行

```powershell
uv venv --python 3.11 .venv
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
.venv\Scripts\python.exe src\main.py
```

打包：`powershell -File build.ps1`，生成 `release\AI虚拟主播.exe`。
